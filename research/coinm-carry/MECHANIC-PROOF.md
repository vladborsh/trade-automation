# MECHANIC-PROOF — the `1/mmr` identity and the ledger

Generated by `mechanic_proof.py`. Identities proven algebraically, then
asserted on **20 real positions** at **every 1 h bar** of each hold, then
ten positions hand-recomputed end to end against the engine.

---

## 1. The algebra

```
q       = N / P_e                  coins in the COIN-M wallet
short   = N USD of XUSD_PERP at P_e, 1x

Binance inverse SHORT P&L, in coin:   PnL(t) = N (1/P_t - 1/P_e)

coin(t) = q + PnL(t)
        = N/P_e + N/P_t - N/P_e
        = N / P_t                                             (I1)

=> USD value of the wallet, marked at P_t:  P_t * N/P_t = N, CONSTANT.

margin(t)      = coin(t)             = N / P_t
maint(t)       = mmr * N / P_t       (position notional in coin)
margin / maint = 1 / mmr             at every price               (I2)
```

`1/mmr` = **250x** on BTCUSD_PERP (bracket-1 mmr 0.40 %) and **200x** on
ETHUSD_PERP (0.50 %). The ratio does not depend on `P_t`, so **there is no
price at which this position can be liquidated** — neither the rally that
killed `H_alts` nor a crash. Marked at the SPOT price instead of the perp
price the coin leg is worth `S_t * N/P_t = N/(1+b_t)`, so the position's
only price exposure is the basis `b_t`, and `hedge_pnl = N/(1+b_x) -
N/(1+b_e)`.
